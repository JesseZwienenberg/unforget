# One-time setup

Everything here happens in a browser. About 15 minutes. You never run a command.

When you are done, the app is live at **https://jessezwienenberg.github.io/unforget/**
and the backend at `https://unforget.<your-subdomain>.workers.dev`.

## The secrets, in one table

All secrets are entered in exactly one place: **GitHub → the `unforget` repo → Settings →
Secrets and variables → Actions → New repository secret**. The deploy workflow copies the
ones the Worker needs to Cloudflare on every deploy. Nothing secret is ever committed.

| Secret name             | Where it comes from                      | Used by                    | Needed from |
| ----------------------- | ---------------------------------------- | -------------------------- | ----------- |
| `CLOUDFLARE_API_TOKEN`  | You create it in Cloudflare (step 2)     | GitHub Actions (deploying) | M0          |
| `CLOUDFLARE_ACCOUNT_ID` | Shown in Cloudflare (step 1)             | GitHub Actions (deploying) | M0          |
| `APP_TOKEN`             | Generated by Claude, shown once in chat  | Worker secret + your phone | M0          |
| `VAPID_PUBLIC_KEY`      | Generated by Claude, shown once in chat  | Worker secret              | M2          |
| `VAPID_PRIVATE_KEY`     | Generated by Claude, shown once in chat  | Worker secret              | M2          |
| `ANTHROPIC_API_KEY`     | You create it in the Claude Console (5)  | Worker secret              | M3          |

The D1 database needs no manual step: the deploy workflow creates it the first time.

## 1. Cloudflare account and account ID

1. Go to https://dash.cloudflare.com/sign-up and create a free account (verify your email).
2. In the left sidebar, open **Workers & Pages** (it may sit under a **Compute** heading). Opening this page
   once gives your account its free `workers.dev` address. If it asks you to pick a
   subdomain, pick anything (e.g. your name).
3. On that same page, find **Account ID** in the right-hand column and copy it. (It is also
   the long code in the address bar: `dash.cloudflare.com/<account id>/…`.)
4. Add it in GitHub as the secret **`CLOUDFLARE_ACCOUNT_ID`** (see "How to add a secret" below).

## 2. Cloudflare API token

1. In Cloudflare, click the person icon (top right) → **My Profile** → **API Tokens** →
   **Create Token**.
2. Next to **Edit Cloudflare Workers**, click **Use template**.
3. Under **Permissions**, click **+ Add more** and add: **Account** · **D1** · **Edit**.
4. Under **Account Resources**: **Include** · your account.
   Under **Zone Resources**: **Include** · **All zones**.
5. **Continue to summary** → **Create Token**. Copy the token (it is shown once).
6. Add it in GitHub as the secret **`CLOUDFLARE_API_TOKEN`**.

## 3. The secrets Claude generated

Add the three values Claude showed you in the chat as **`APP_TOKEN`**,
**`VAPID_PUBLIC_KEY`** and **`VAPID_PRIVATE_KEY`**.

Keep the `APP_TOKEN` somewhere safe as well (a password manager): in M1 you need it once
more for the setup link on your phone.

## 4. Turn on GitHub Pages

1. Open https://github.com/JesseZwienenberg/unforget/settings/pages
2. Under **Build and deployment** → **Source**, choose **GitHub Actions**. That's all; there
   is no save button.

## 5. Anthropic API key (can wait until M3)

1. Go to https://console.anthropic.com (it may forward you to platform.claude.com) and sign in.
2. **Settings** → **Billing** → add a payment method and buy the minimum credit ($5).
   Turn **auto-reload off**, so the spend can never exceed what you bought.
3. **Settings** → **API keys** → **Create key**, name it `unforget`, copy it.
4. Add it in GitHub as the secret **`ANTHROPIC_API_KEY`**.

## 6. Run the deploy

1. Open https://github.com/JesseZwienenberg/unforget/actions/workflows/deploy.yml
2. Click **Run workflow** → **Run workflow** (branch `main`).
3. Wait for the green check (about 2 minutes). Click the run: the summary at the bottom
   shows the app address and the Worker address.

If a step is red, click it, copy the red error line and paste it to Claude.

## How to add a secret

1. Open https://github.com/JesseZwienenberg/unforget/settings/secrets/actions
2. **New repository secret**.
3. **Name**: exactly as in the table (capitals and underscores). **Secret**: the value, with
   no spaces or line breaks around it.
4. **Add secret**.

## Rotating the app token

Ask Claude for a new token (or use any long random string), replace the `APP_TOKEN` secret
in GitHub, and run the Deploy workflow again. The old token stops working as soon as the
deploy finishes. Then open the new setup link on each device (from M1).
